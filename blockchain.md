# Blockchain

Blockchain é um registro distribuído de dados, organizado em blocos encadeados e validado por consenso entre os nós de uma rede, sem autoridade central.

## Conceitos
- Blocos encadeados por hash
- Rede peer-to-peer
- Algoritmo de consenso distribuído
- Criptografia

## Exemplos e lugares aplicados
Criptomoedas (Bitcoin), contratos inteligentes, rastreabilidade de cadeia de suprimentos.

## Minhas anotações da aula
As tecnologias blockchain não são uma técnica única: reúnem criptografia, matemática, algoritmos e modelo econômico, combinando redes peer-to-peer e algoritmo de consenso distribuído para resolver o problema tradicional de banco de dados distribuído, em uma construção de infraestrutura integrada de vários campos.

Seis elementos-chave:
- Descentralizado: característica básica; não é preciso confiar em um nó central, e os dados podem ser gravados, armazenados e atualizados de forma distribuída.
- Transparente: o registro dos dados é transparente para cada nó, assim como suas atualizações, e é por isso que o blockchain pode ser confiável.
- Código aberto: a maioria dos sistemas é aberta a todos, os registros podem ser verificados publicamente e qualquer pessoa pode criar aplicativos usando a tecnologia.
- Autonomia: com a base de consenso, cada nó pode transferir ou atualizar dados com segurança, sem confiar em uma única pessoa, e ninguém pode intervir.
- Imutável: os registros são guardados para sempre e não podem ser alterados, a menos que alguém controle mais de 51% dos nós ao mesmo tempo.
- Anonimato: resolve o problema de confiança entre os nós; a transferência de dados ou transação pode ser anônima, bastando conhecer o endereço blockchain da pessoa.
