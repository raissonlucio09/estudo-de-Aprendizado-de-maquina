# Lógica Fuzzy

A lógica fuzzy (nebulosa) trabalha com graus de verdade entre 0 e 1, em vez de apenas verdadeiro ou falso, o que permite modelar conceitos vagos como "quente", "alto" ou "rápido".

Conceitos
- Variáveis linguísticas
- Conjuntos fuzzy e funções de pertinência
- Regras fuzzy do tipo SE-ENTÃO
- Fuzzificação e defuzzificação

Exemplos e lugares aplicados
Ar-condicionado, máquina de lavar, freios ABS e outros sistemas de controle.

Minhas anotações da aula
Normalmente um sistema que utiliza Lógica Fuzzy é composto de:
1. Fuzzificação
2. Avaliação das regras
3. Agregação das saídas das regras
4. Defuzzificação

Um processo típico de desenvolvimento de um sistema especialista Fuzzy segue estes passos:
- Especificar o problema e definir as variáveis linguísticas
- Determinar os conjuntos Fuzzy
- Construir as regras Fuzzy
- Relacionar os conjuntos Fuzzy, as regras Fuzzy, os procedimentos e a inferência Fuzzy
- Avaliar os resultados do sistema
